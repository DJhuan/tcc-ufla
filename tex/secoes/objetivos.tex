\section{Objetivos}

Considerando o exposto, objetivos foram determinados como guia de desemvolvimento e noção de sucesso do trabalho realizado.

\subsection{Objetivo Geral}

Este trabalho tem como propósito o desenvolvimento de uma aplicação web de visualização molecular tridimensional baseada em realidade virtual, capaz de representar simultaneamente múltiplas moléculas no espaço e permitir a análise interativa.

\subsection{Objetivos Específicos}
Para alcançar o objetivo geral proposto, foram definidos os seguintes objetivos específicos:

\begin{itemize}
	\item Implementar a renderização tridimensional de estruturas moleculares;
	\item Implementar importação de moléculas a partir de arquivos PDB \textit{Protein Data Bank} e CIF \textit{Crystallographic Information Framework};
	\item Implementar algoritmo para definir ligações atômicas da molécula importada;
	\item Possibilitar a visualização e interação em ambiente de realidade virtual;
	\item Desenvolver uma interface responsiva e acessível para dispositivos de apresentação de realidade extendida;
	\item Implementar suporte à visualização simultânea de duas moléculas no mesmo ambiente virtual;
	\item Permitir a manipulação livre das moléculas no espaço tridimensional, possibilitando o alinhamento e a análise visual de suas áreas.
\end{itemize}
